# 买家：浏览、下单与收货

## 浏览和找商品

**搜索**：在顶部搜索框输入关键词（例如「键盘」），回车。

**按分类**：点首页的「电子产品」「图书音像」等标签。

**按价格和排序**：在列表页填最低价、最高价，或者切换「价格从低到高」，列表会立刻变化，不需要再点确认按钮。

**商品详情页**能看到：价格、剩余库存、已售数量、浏览次数、卖家写的商品描述、买家的评价。

## 加入购物车

在商品详情页点「加入购物车」。**加入购物车不占用库存**，同一件商品可以多人同时放进各自的购物车。

如果商品显示「已售罄」，购买按钮不可点，但商品仍然可以查看，评价入口和相关推荐也照常显示。

## 提交订单

1. 顶部点「购物车」；
2. 右侧是一张结算小票，勾选或取消勾选商品，小票上的合计金额会跟着变；
3. 点「提交订单」，页面跳到订单详情。

下单成功后订单是**待付款**状态，订单右边的购物小票上会盖一个「待付款」章。

## 付款

在订单详情页点「付款」。平台是演示环境，点付款只改状态，不会真的扣钱。付款成功后状态变成「已付款，等待发货」。

## 订单状态

| 状态 | 含义 | 这个状态下能做什么 |
|---|---|---|
| 待付款 | 已下单，还没付款 | 付款、取消订单 |
| 已付款 | 钱已付，卖家还没发货 | 取消订单（未发货时可以） |
| 已发货 | 卖家已经发货 | 确认收货 |
| 交易完成 | 已确认收货 | 评价商品 |
| 已取消 | 订单已取消 | 无 |

订单页顶部可以按状态筛选，每个标签上带数量。

## 取消订单

**待付款**和**已付款但卖家还没发货**这两种状态可以取消，买家本人和管理员都能操作。

取消成功后**库存会自动退回**，商品重新变成可购买状态。已经发货的订单没有「取消订单」按钮。

## 确认收货

卖家发货后，订单详情页会出现「确认收货」按钮。点它，订单变成「交易完成」。

确认收货之后才能评价这件商品。

## 未付款订单会被自动取消

提交订单后如果一直不付款，**30 分钟后系统会自动取消这笔订单并把库存退回**。这个时限是平台配置项，默认 30 分钟。

自动取消和自己手动取消的效果一样：订单变成「已取消」，库存回到商品上。

## 收藏

在商品详情页点「收藏」，按钮变成黄色的「已收藏」。顶部「收藏」页能看到所有收藏的商品，每件下面都可以「移出收藏」。
