# 账号与个人中心

## 注册

在登录页点「还没有账号？去注册」，填写三项：

- **用户名**：登录用，注册后不能改。
- **昵称**：别人看到的名字，选填。不填就用用户名。
- **密码**：至少 6 位，需要输入两次确认。

注册成功后回到登录页，用刚填的用户名和密码登录。

## 登录与登录状态

- 登录成功后浏览器会保存登录状态，**刷新页面、关掉标签页再打开，仍然是登录状态**。
- 登录凭证放在浏览器的 Cookie 里，页面的 JavaScript 读不到它，所以不存在「前端明文存令牌」的问题。
- 想看当前登录的是谁，点右上角头像；头像菜单里有「个人中心」和「退出登录」。

## 个人中心

右上角头像 → 「个人中心」，可以改三样东西：

**改昵称**
改完点「保存修改」，页面右上角显示的名字会立刻跟着变。

**换头像**
点会员证上的头像选中一张本地图片，再点「保存修改」生效。

**改密码**
输入旧密码和新密码，保存后会要求用新密码重新登录。**改密码会让所有设备上已登录的会话立即失效**，其他电脑或手机上的登录都会被踢掉。这是有意设计的：密码一旦泄露，改密码应该能立刻收回所有旧凭证。

## 账号被禁用会怎样

管理员可以在后台禁用某个账号。被禁用的账号：

- 已经登录的会话**下一次操作就会提示登录失效**，需要重新登录；
- 重新登录会被拒绝，无法再登录；
- 管理员点「启用」后恢复正常。

## 游客能做什么

不登录也能浏览平台大部分内容：

- 首页商品列表、搜索、分类筛选、价格区间与排序；
- 在售商品的详情页、买家评价、相关推荐；
- 热门推荐。

需要登录才能做的操作：**加入购物车、收藏、下单、付款、确认收货、评价、发布商品、查看自己的订单**。在未登录时点这些按钮会提示「请先登录」并跳转到登录页，登录完成后会自动回到刚才那个商品页。
